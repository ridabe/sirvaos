# SirvaOS

**SirvaOS: organize para servir melhor.**

Plataforma SaaS para gestão de igrejas, ministérios, membros, escalas, eventos e comunicação.

## Desenvolvimento

```bash
npm install
npm run dev
```

Aplicação local:

```text
http://127.0.0.1:5173
```

Build de produção:

```bash
npm run build
```

## Stack Inicial

- React
- TypeScript
- Vite
- Lucide React
- CSS com tokens da identidade visual SirvaOS
